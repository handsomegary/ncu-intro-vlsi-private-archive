# 2022 midterm

Original PDFs and photograph panels mentioned below are stored only in the owner-only [private original archive](https://github.com/handsomegary/ncu-intro-vlsi-originals), under the same `homework/` or `exams/` path. This public folder contains the authored reports, reconstructions and verification evidence.

Complete printed original Q1–Q6, 100 points. The question and corrected solution PDFs are reconstructed in standalone editable LaTeX/TikZ. Original page photographs retain their image bytes; local student identities and answer scans are not reproduced in the typeset reports.

Files: `exam.tex`/`exam.pdf`, `solution.tex`/`solution.pdf`, `original-exam.pdf`, `sources.json`, `SOURCES.md`, and analytical `verify.py` with CSV/JSON results. Run `python verify.py`. Compile either standalone source using `pdflatex -interaction=nonstopmode -halt-on-error exam.tex` or `solution.tex`.

The solution derives from original functions and circuits before comparing supplied answers. It corrects static leakage/body-effect explanations, distributed TG delay, buffer-stage indexing and changed PMOS gate loads, and the XOR driving-strength description. Oxidation/bonding classifications are explicit alternatives. Q6 resistance/load symbols remain symbolic when not specified. No proprietary process model or fabricated simulation evidence is required.
