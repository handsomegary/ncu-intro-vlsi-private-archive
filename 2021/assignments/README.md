# Original 2021 assignment PDFs

`homework1.pdf` through `homework4.pdf` are byte-for-byte copies of the supplied original prompts. The source of HW3 was named `homework3 .pdf`; only its destination filename was normalized. HW4 includes layout in the original prompt, but this task explicitly requests only its pre-layout SPICE scope.

The original HW1 3(a) has an overbar over the entire sum. The original HW3/HW4 labels F as the internal NAND node and Z as the AND output. These details were checked visually, rather than inferred from PDF text extraction.
