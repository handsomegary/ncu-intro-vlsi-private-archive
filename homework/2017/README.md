# 2017 Introduction to VLSI Design solutions

Original PDFs and photograph panels mentioned below are stored only in the owner-only [private original archive](https://github.com/handsomegary/ncu-intro-vlsi-originals), under the same `homework/` or `exams/` path. This public folder contains the authored reports, reconstructions and verification evidence.

Available original assignments: HW1, HW2, HW3, HW4. Every available original prompt has a complete English standalone `.tex` report, rendered PDF, reproducible verification, and comparison with supplied answers.

Original PDFs are preserved byte-for-byte in `assignments/`. Each homework README gives commands and conditions. Simulation drivers use the user's local `D:/cic018.l`, accept `--model`, `--hspice`, and `--work`, and keep raw logs outside the deliverable folders. The process library is never redistributed.

HW1/HW2 are theory tasks in the actual prompts and include diagrams/derivations plus executable calculators. HW3 includes both equal-size AND-gate delays and a corrected short-circuit-power curve. HW4 includes both the28-transistor mirror adder and 34-transistor dual-rail domino adder, calibrated to a declared1% rise/fall balance target; no layout is requested.

See `SOURCES.md` for primary prompts, reference hashes, retained choices, and corrections.
